# 상황이음 — 내부망용 재난상황보고 시제품

가상 상황 입력 → 항목별 초안 편집 → 기존 HWPX 서식 다운로드를 시험하는 로컬 웹앱입니다.
현재 자연어 처리는 **규칙 기반 데모**이며 생성형 AI 또는 네이버웍스 AI에 연결되지 않았습니다.

## 필수 정보 입력

발생일시·장소·사고개요·인명피해를 기본 필수 항목으로 지정했습니다. 기관의 확정된 필수 항목 목록이 아니라 시제품 기본값입니다.
목록은 `report.mjs`의 `requiredFields`에서 변경할 수 있으며 화면과 서버가 같은 설정을 사용합니다.
초안 반영 후 누락된 항목만 입력 팝업으로 표시합니다. 빈 값·공백은 허용하지 않고,
Esc와 바깥 클릭으로 닫을 수 없습니다. ‘확인 중으로 입력’ 버튼으로 미확인 상태를 명시할 수 있습니다.
완료 버튼을 누르면 보고서에 반영됩니다. 이후 필수 값을 지우고 다른 항목으로 이동하면 다시 입력을 요구합니다.
본문 복사와 다운로드 전에도 확인하며, 서버에서 직접 파일 생성을 요청해도 필수 항목 누락 시 거부합니다.
필수 입력은 기재 여부를 검사하며, 기재한 사실의 정확성이나 진위까지 판정하지 않습니다.

## 실행

Node.js 20 이상이 필요합니다. 최초 개발 설치는 `npm.cmd ci`, 실행은 `npm.cmd start`입니다.
Windows에서는 `start.cmd`를 더블클릭해도 됩니다. 브라우저에서 http://127.0.0.1:3210 으로 접속하세요.
서버 종료는 실행 창에서 Ctrl+C입니다.

1. ‘가상 화재 상황 불러오기’를 누르고 ‘초안에 반영’을 누릅니다.
2. 오른쪽의 항목을 직접 수정합니다. 직접 수정한 항목은 표시됩니다.
3. 추가 메모가 기존 값과 다르면 변경 후보를 확인하고 적용 또는 유지를 선택합니다.
4. HWPX 다운로드를 누릅니다. 출력 파일은 한글 프로그램에서 최종 확인하세요.
5. 새 보고서 버튼으로 내용을 초기화합니다. 새로고침·브라우저 종료 시 입력이 사라집니다.

`장소: 가상시 가상동`처럼 화면의 항목명을 사용하면 정확히 배치됩니다. 일반 문장은
키워드로 분류합니다. 원문은 사고개요에도 들어가므로 중복 표현은 직원이 다듬어야 합니다.
날짜 추정, 피해 인원 합산, 모호한 증감 처리, 사실 판정, 보고 문체 윤문은 하지 않습니다.
‘신고 없음’, ‘확인 중’, ‘예정’ 표현을 그대로 유지합니다. 연대기 자동 정렬은 아직 지원하지 않습니다.

## 서식 처리

`templates/report.hwpx`는 제공된 `재난상황보고서[1].hwpx`의 복사본입니다.
Kordoc 4.24.12의 `patchHwpx`로 원본 표·중첩표 골격을 유지하며 내용을 교체합니다.
`report.mjs`의 `sections`와 `buildMarkdown`이 화면 항목과 출력 위치의 대응을 정의합니다.
생성 후 Kordoc으로 다시 파싱해 입력 문구가 빠짐없이 포함됐는지 검사합니다.
원본의 예시 수치와 예시 상황은 출력에서 제거하고 미입력 값으로 대체합니다.
다운로드 검증은 내용 검증이며 한글에서의 최종 조판 보증은 아닙니다.
긴 문장은 원본의 고정 높이 표에서 넘칠 수 있으므로 실제 배포 전 문량별 한컴 검증이 필요합니다.

## 내부망 이관

런타임은 외부 AI·CDN·웹폰트·원격 API를 호출하지 않습니다. Kordoc은 오프라인 모드로 실행합니다.
MCP 설치는 앱 사용자에게 필요하지 않습니다. 서버가 Kordoc 라이브러리를 직접 사용합니다.
인터넷이 가능한 개발 환경에서 의존성을 미리 확보해야 하며, 내부망 서버와 동일한 OS·CPU에서
`npm.cmd ci`한 결과와 Node.js 런타임을 기관 절차에 따라 반입해야 합니다. 실행 중 패키지를 다운로드하지 않습니다.

현재 서버는 localhost 전용이며 로그인·접근 권한·영구 저장·공동 편집·감사 이력이 없습니다.
다중 사용자 내부망 운영에 그대로 노출하지 마세요. 운영 단계에서는 내부 AI API 연결,
기관 인증, HTTPS, 접근 제어, 보관 정책과 서버 배포 구성을 추가해야 합니다.
입력 메모는 브라우저 메모리에만 보관되고 서버에는 파일로 저장하지 않습니다.
HWPX 생성 시 서버 메모리에서 처리하며 다운로드 파일은 사용자 브라우저 설정에 따라 저장됩니다.

검증: `npm.cmd test`. 시각 검증용 샘플은 `artifacts/`에 별도로 생성할 수 있습니다.
